# A2 — kontrakt i wdrożenie

Indeks całej dokumentacji: [README.md](README.md).

## Zakres A2 (zamknięty w kodzie)

| Wymaganie | Implementacja |
|-----------|----------------|
| ZIP | `ingest.extract_zip` + `pipeline._run_zip_job` |
| Wynik per plik w ZIP | `storage/results/{folder}/{ścieżka}/result.json\|txt` — `folder` = stem ZIP lub UUID (patrz `RESULTS_DIR_USE_SOURCE_NAME`) |
| Limit 15 GB | `max_upload_bytes`, `max_zip_uncompressed_bytes` |
| Postęp | `GET /jobs/{id}` → `progress` (`pages` / `files`) |
| Kolejka (Redis + RQ) | `USE_BACKGROUND_WORKER=true` → enqueue, worker OCR |
| Snapshot joba | `storage/results/{folder}/job.json` po `done` / `failed` (`results_folder` w job store) |

Poza A2: panel WWW, pola `structured`, fast/bulk/vision queues (optymalizacja później).

## Wdrożenie produkcyjne

```bash
# 1. Redis
sudo apt install -y redis-server
sudo systemctl enable --now redis-server
redis-cli ping   # PONG

# 2. Konfiguracja
cp .env.example .env
# USE_BACKGROUND_WORKER=true  (domyślnie w .env.example)

# 3. API
source .venv/bin/activate
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 4. Worker (drugi terminal / systemd)
./scripts/run_rq_worker.sh
```

## Integracja API (async)

```bash
# Upload
curl -s -X POST http://127.0.0.1:8000/api/v1/jobs \
  -F "file=@samples/paragon_1.jpg" | jq .

# Poll (status: queued → processing → done)
JOB_ID="<uuid z odpowiedzi>"
curl -s "http://127.0.0.1:8000/api/v1/jobs/$JOB_ID" | jq .

# Wynik (pojedynczy plik)
curl -s "http://127.0.0.1:8000/api/v1/jobs/$JOB_ID/result.json" | jq .

# ZIP — lista plików wynikowych
curl -s "http://127.0.0.1:8000/api/v1/jobs/$JOB_ID/results" | jq .
curl -s "http://127.0.0.1:8000/api/v1/jobs/$JOB_ID/files/folder/doc.pdf/result.txt"
```

## Dev bez Redis

W `.env`: `USE_BACKGROUND_WORKER=false` — `POST /jobs` wykonuje OCR synchronicznie (jak A1).
